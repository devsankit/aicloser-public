# Closer clone

Self-contained HTML/CSS/JS reconstruction of the AI Closer Framer marketing page, rebranded for Closer.

## Run locally

Open `index.html` directly, or serve this folder with any static server:

```powershell
cd outputs/bardy-clone
npx serve .
```

The implementation includes responsive desktop/tablet/mobile layouts, word-level text reveals, scroll reveals, animated SVG pipeline lines, an animated testimonial marquee, interactive feature tabs, FAQ accordions, the trial countdown, a mobile navigation menu, hover states, and reduced-motion support.
