# AI Closer — Next.js migration

This workspace now contains a typed Next.js App Router shell with Tailwind CSS. The existing visual system and reference assets are preserved in the migration so the design and motion remain stable while the runtime moves from a static HTML page to React/TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:4175/`.

Useful checks:

```bash
npm run typecheck
npm run build
```
